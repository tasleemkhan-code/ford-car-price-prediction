
# Ford Car Price Prediction

## Project Overview
This project uses machine learning to predict used Ford car prices based on vehicle features.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook
- Machine Learning

## Work Completed
- Data preprocessing
- Categorical feature encoding
- Regression model training
- Model evaluation using R² and Adjusted R²

## Dataset
Ford car dataset containing features such as model, year, transmission, mileage, fuel type, tax, mpg, engine size, and price.

## Purpose
This project was developed for machine learning practice and learning purposes.
